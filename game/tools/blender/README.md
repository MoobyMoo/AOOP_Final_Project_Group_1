# Character pipeline (Blender 5.2, headless)

Every character asset is generated by script; nothing is modelled by hand, downloaded or generated by AI.

```
blender -b --factory-startup --python tools/blender/build_monkey.py     # -> public/models/monkey.glb
blender -b --factory-startup --python tools/blender/build_gorilla.py    # -> public/models/gorilla.glb
blender -b --factory-startup --python tools/blender/build_wearables.py  # -> public/models/wearables.glb
tools/blender/qa.sh                                                     # asset QA gate (run after the builds)
blender -b tools/blender/build/monkey.blend --python-exit-code 1 --python tools/blender/clip_check.py -- --clean dash --ground dash   # clip gate: loop pops, one-frame spikes, clean start/end
blender -b tools/blender/build/gorilla.blend --python-exit-code 1 --python tools/blender/clear_check.py -- --skip sleep              # boss helmet never inside an arm or pauldron, every clip
```
Options: `-- --sheet out.png` renders an Eevee turnaround (front, 3/4, side, back); `-- --poses <dir> run:8,melee:6`
renders clip strips. Editable `.blend` files land in `tools/blender/build/` (ignored by git; the scripts are the source).

| File | What it holds |
|---|---|
| `bv_common.py` | mesh helpers (cube-sphere, loft, tube, surface plates), subdivision, AO bake, weights, armature, GLB export, renders |
| `monkey_parts.py` | every monkey part mesh + the joint positions (`J`, `TAIL`) |
| `monkey_anim.py` | monkey clips and gait table (`GAITS`, `GAIT_LEN`) |
| `bv_anim.py` | pose solver (FK spine, two-bone IK hands/feet) and clip baking |
| `build_*.py` | assembly: parts, armature, weights, AO, shape keys, clips, export |

## Stable interface (other meshes get rigged to this: do not rename)

**Space.** Blender: +X = the character's left, -Y = forward, +Z = up, metres. glTF/three.js: x left, y up, +z forward.

**Monkey armature `MonkeyRig`** (34 joints; every bone's local Z points forward, local Y runs along the bone):

| Bone | Parent | Head (x, forward, up) |
|---|---|---|
| root | - | 0, 0, 0 |
| hips | root | 0, 0, 0.50 |
| spine | hips | 0, 0, 0.62 |
| chest | spine | 0, 0, 0.78 |
| neck | chest | 0, 0, 0.98 |
| head | neck | 0, 0, 1.04 |
| ear_L / ear_R | head | ±0.50, -0.03, 1.475 |
| shoulder_L / _R | chest | ±0.08, 0, 0.93 |
| upperarm_L / _R | shoulder | ±0.275, 0, 0.925 |
| forearm_L / _R | upperarm | ±0.425, 0.005, 0.70 |
| hand_L / _R | forearm | ±0.53, 0.03, 0.48 |
| thumb_L / _R | hand | fist centre + 0.06 along the thumb side |
| thigh_L / _R | hips | ±0.145, 0, 0.46 |
| shin_L / _R | thigh | ±0.15, 0.012, 0.27 |
| foot_L / _R | shin | ±0.155, 0, 0.10 |
| tail1..tail5 | hips, chain | 0,-0.24,0.445 / 0,-0.40,0.41 / 0,-0.56,0.405 / 0,-0.71,0.47 / 0,-0.82,0.60 (tip 0,-0.85,0.78) |
| sk_hand_L / _R | hand | fist centre ±0.568, 0.042, 0.395; local +Z = barrel, +Y = gun up (thumb side) |
| sk_head | head | top of the head 0, 0.02, 1.915; +Y up, +Z forward |
| sk_face | head | on the face between the eyes; +Y up, +Z forward |
| sk_back | chest | 0, -0.255, 0.80; +Y up, +Z forward |

Bind pose: relaxed A-pose, arms ~35 deg from vertical, legs straight, palms toward the thighs.
**Gorilla armature `GorillaRig`** (25 joints): the same names without ears, thumbs and tail; bind pose is the knuckle stance.

**Colour zones.** Colour is not baked. Each face carries a zone id and each vertex an AO value, exported in the UV channel:
`u = (zone + 0.5) / 48`, `v = ao`. Zone ids (index = id; append only, never reorder; mirrored in `src/game/actors/charmat.ts`):

`fur face suit pants tie feet shirt dark white pupil gold mouth tongue suit2 stripeA stripeB sole prop prop2 fur2 skin metal red cloth chain mask hat band lens leather leather2 banana green blue pink yellow khaki wood wood2 glass skin2 vest vest2 nail ear square navy leaf`

`navy` and `leaf` were added for the G1-23 gear (48 slots, 48 used: the palette is full; a 49th zone needs `NREG` raised in
`bv_common.py` and `charmat.ts` together).

Body zones a replacement body mesh must use: `fur` (head, tail, bare limbs), `face` (face plate, muzzle, hands), `ear` (inner ear),
`pupil` (eyes), `dark` (brows, nostrils, mouth line), `suit` (jacket), `suit2` (lapels, hem underside), `shirt`, `tie`, `gold` (buttons),
`square` (pocket square), `pants`, `feet`, `sole`.

**Parts.** Mesh objects are named `p_<slot>_<style>`; the runtime merges one style per slot into a single skinned mesh:
`head`, `ears_{round,pointy,floppy}`, `eyes_/lids_{round,sleepy,sparkle,beady}`, `brows_{bold,thin,bushy}`, `mouth_{smile,grin,smirk,toothy,whistle}`,
`torso_{suit,vest,fur,tee}` (torso + arms + legs), `front_{two,double,vest,open}` (suit front), `tie_{tie,bowtie}`, `square`, `hands`,
`feet_{round,shoes}`, `tail`, `tuft`. Gorilla: `body`, `face`, `vest`, `sleepmask`, `chain` (the Sleeper), `boss_plates`, `boss_helmet` (the boss).

**The boss gorilla (G1.5 row 26)** is the brute's body and skeleton plus two parts, so every gorilla clip plays on it: `boss_plates` (breastplate, two back
plates with a row of spikes, dome pauldrons, forearm bracers, belt) and `boss_helmet` (an open-top steel band with two banana horns). The armour covers the
body and leaves the scalp and face bare, so the head reads as the place to shoot. Zones: `metal` plate, `yellow` trim, `nail` spikes and studs, `leather` +
`gold` belt, `banana` + `prop2` horns (recolour them through the palette). Review scale 1.35 (the Sleeper is 1.26); 8,624 tris with the body.
Its escorts are bandits in `guard_helmet` (head) and `guard_plate` (body) from `wearables.glb`, in the same steel-and-yellow language.

**Shape keys.** `blink` (lids), `eyeWide` (eyes, lids, brows: +15 % spacing at 1), `browTilt` (brows: +24 deg scheming at 1),
`build` (torso, front, tie, square: chubby at +1, driven negative for slim). Head size, ear size and tail curl are bone scales /
rotations in the runtime, so hats, glasses and sockets follow.

**Wearables** sit in socket space (origin at the socket, same axes as the character) as one node per id in `wearables.glb`.

| Slot | Socket | Origin (x, forward, up) | How the runtime wears it |
|---|---|---|---|
| head | bone `sk_head` | top of the head | rigid on the socket |
| face | bone `sk_face` | on the face between the eyes | rigid on the socket |
| back | bone `sk_back` | 0, -0.255, 0.80 | rigid; the socket scales with the build, and a little more over body armour |
| body | the `chest` joint | 0, 0, 0.78 | skinned: `rig.ts` gives every vertex the torso's weights (hips / spine / chest by height) and the torso's `build` shape key, then merges the piece into the character mesh. A rigid vest would tear at the belly whenever the chest twists against the hips. |
| ears | on bone `head` | 0, 0.035, 1.425 (between the ears) | rigid; headsets ship two meshes: `<id>` (band over the bare head) and `<id>_nb` (band round the back of the head), and the runtime picks `_nb` whenever a hat is worn |

Body pieces must stay outside the suit with its lapels, buttons and tie (lift >= 0.03 on the chest) and must use zones
the body does not use (not `fur face suit pants tie feet shirt dark white pupil gold mouth tongue suit2 stripeA stripeB
sole fur2 ear square`), because they share the character's palette: the runtime recolours and dulls (broken armour) every
other zone as armour.

## Clips
Monkey (30 fps samples): loops `idle walk run runBack strafeL strafeR cheer`, poses `aim carry`, timed `fire reload melee roll dash hurt throw use defeat`.
`dash` (G1.5 row 14) is the ninja dash that replaces the roll: 20 frames played over 0.34 s, a low forward lunge with the arms swept back. It starts and ends on the same ready stance and eases out of and into it (drop in 0-0.2, hold 0.2-0.74, recover 0.74-1).
Gorilla: loops `idle walk charge stunned sleep`, timed `windup slam hurt defeat`. Timed clips play at `actionT x clip length`.
Gaits are stride-matched: one cycle covers `GAIT_LEN` metres (walk 0.8, run 2.2, runBack 1.64, strafe 1.18).
