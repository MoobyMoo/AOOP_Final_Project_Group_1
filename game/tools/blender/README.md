# Character pipeline (Blender 5.2, headless)

Every character asset is generated by script; nothing is modelled by hand, downloaded or generated by AI.

```
blender -b --factory-startup --python tools/blender/build_monkey.py     # -> public/models/monkey.glb
blender -b --factory-startup --python tools/blender/build_gorilla.py    # -> public/models/gorilla.glb
blender -b --factory-startup --python tools/blender/build_wearables.py  # -> public/models/wearables.glb
tools/blender/qa.sh                                                     # asset QA gate (run after the builds)
blender -b tools/blender/build/monkey.blend --python-exit-code 1 --python tools/blender/clip_check.py -- --clean dash --ground dash   # clip gate: loop pops, one-frame spikes, clean start/end
blender -b tools/blender/build/gorilla.blend --python-exit-code 1 --python tools/blender/clear_check.py -- --skip sleep              # boss helmet never inside an arm or pauldron, every clip
```
Options: `-- --sheet out.png` renders an Eevee turnaround (front, 3/4, side, back); `-- --poses <dir> run:8,melee:6`
renders clip strips. Editable `.blend` files land in `tools/blender/build/` (ignored by git; the scripts are the source).

| File | What it holds |
|---|---|
| `bv_common.py` | mesh helpers (cube-sphere, loft, tube, surface plates), subdivision, AO bake, weights, armature, GLB export, renders |
| `monkey_parts.py` | every monkey part mesh + the joint positions (`J`, `TAIL`) |
| `monkey_anim.py` | monkey clips and gait table (`GAITS`, `GAIT_LEN`) |
| `bv_anim.py` | pose solver (FK spine, two-bone IK hands/feet) and clip baking |
| `build_*.py` | assembly: parts, armature, weights, AO, shape keys, clips, export |

## Stable interface (other meshes get rigged to this: do not rename)

**Space.** Blender: +X = the character's left, -Y = forward, +Z = up, metres. glTF/three.js: x left, y up, +z forward.

**Monkey armature `MonkeyRig`** (34 joints; every bone's local Z points forward, local Y runs along the bone):

| Bone | Parent | Head (x, forward, up) |
|---|---|---|
| root | - | 0, 0, 0 |
| hips | root | 0, 0, 0.50 |
| spine | hips | 0, 0, 0.62 |
| chest | spine | 0, 0, 0.78 |
| neck | chest | 0, 0, 0.98 |
| head | neck | 0, 0, 1.04 |
| ear_L / ear_R | head | ±0.50, -0.03, 1.475 |
| shoulder_L / _R | chest | ±0.08, 0, 0.93 |
| upperarm_L / _R | shoulder | ±0.275, 0, 0.925 |
| forearm_L / _R | upperarm | ±0.425, 0.005, 0.70 |
| hand_L / _R | forearm | ±0.53, 0.03, 0.48 |
| thumb_L / _R | hand | fist centre + 0.06 along the thumb side |
| thigh_L / _R | hips | ±0.145, 0, 0.46 |
| shin_L / _R | thigh | ±0.15, 0.012, 0.27 |
| foot_L / _R | shin | ±0.155, 0, 0.10 |
| tail1..tail5 | hips, chain | 0,-0.24,0.445 / 0,-0.40,0.41 / 0,-0.56,0.405 / 0,-0.71,0.47 / 0,-0.82,0.60 (tip 0,-0.85,0.78) |
| sk_hand_L / _R | hand | fist centre ±0.568, 0.042, 0.395; local +Z = barrel, +Y = gun up (thumb side) |
| sk_head | head | top of the head 0, 0.02, 1.915; +Y up, +Z forward |
| sk_face | head | on the face between the eyes; +Y up, +Z forward |
| sk_back | chest | 0, -0.255, 0.80; +Y up, +Z forward |

Bind pose: relaxed A-pose, arms ~35 deg from vertical, legs straight, palms toward the thighs.
**Gorilla armature `GorillaRig`** (25 joints): the same names without ears, thumbs and tail; bind pose is the knuckle stance.

**Colour zones.** Colour is not baked. Each face carries a zone id and each vertex an AO value, exported in the UV channel:
`u = (zone + 0.5) / 48`, `v = ao`. Zone ids (index = id; append only, never reorder; mirrored in `src/game/actors/charmat.ts`):

`fur face suit pants tie feet shirt dark white pupil gold mouth tongue suit2 stripeA stripeB sole prop prop2 fur2 skin metal red cloth chain mask hat band lens leather leather2 banana green blue pink yellow khaki wood wood2 glass skin2 vest vest2 nail ear square navy leaf`

`navy` and `leaf` were added for the G1-23 gear (48 slots, 48 used: the palette is full; a 49th zone needs `NREG` raised in
`bv_common.py` and `charmat.ts` together).

Body zones a replacement body mesh must use: `fur` (head, tail, bare limbs), `face` (face plate, muzzle, hands), `ear` (inner ear),
`pupil` (eyes), `dark` (brows, nostrils, mouth line), `suit` (jacket), `suit2` (lapels, hem underside), `shirt`, `tie`, `gold` (buttons),
`square` (pocket square), `pants`, `feet`, `sole`.

**Parts.** Mesh objects are named `p_<slot>_<style>`; the runtime merges one style per slot into a single skinned mesh:
`head`, `ears_{round,pointy,floppy}`, `eyes_/lids_{round,sleepy,sparkle,beady}`, `brows_{bold,thin,bushy}`, `mouth_{smile,grin,smirk,toothy,whistle}`,
`torso_{suit,vest,fur,tee}` (torso + arms + legs), `front_{two,double,vest,open}` (suit front), `tie_{tie,bowtie}`, `square`, `hands`,
`feet_{round,shoes}`, `tail`, `tuft`. Gorilla: `body`, `face`, `vest`, `sleepmask`, `chain` (the Sleeper), `boss_plates`, `boss_helmet` (the boss).

**The boss gorilla (G1.5 row 26)** is the brute's body and skeleton plus two parts, so every gorilla clip plays on it: `boss_plates` (breastplate, two back
plates with a row of spikes, dome pauldrons, forearm bracers, belt) and `boss_helmet` (an open-top steel band with two banana horns). The armour covers the
body and leaves the scalp and face bare, so the head reads as the place to shoot. Zones: `metal` plate, `yellow` trim, `nail` spikes and studs, `leather` +
`gold` belt, `banana` + `prop2` horns (recolour them through the palette). Review scale 1.35 (the Sleeper is 1.26); 8,624 tris with the body.
Its escorts are bandits in `guard_helmet` (head) and `guard_plate` (body) from `wearables.glb`, in the same steel-and-yellow language.

**Shape keys.** `blink` (lids), `eyeWide` (eyes, lids, brows: +15 % spacing at 1), `browTilt` (brows: +24 deg scheming at 1),
`build` (torso, front, tie, square: chubby at +1, driven negative for slim). Head size, ear size and tail curl are bone scales /
rotations in the runtime, so hats, glasses and sockets follow.

**Wearables** sit in socket space (origin at the socket, same axes as the character) as one node per id in `wearables.glb`.

| Slot | Socket | Origin (x, forward, up) | How the runtime wears it |
|---|---|---|---|
| head | bone `sk_head` | top of the head | rigid on the socket |
| face | bone `sk_face` | on the face between the eyes | rigid on the socket |
| back | bone `sk_back` | 0, -0.255, 0.80 | rigid; the socket scales with the build, and a little more over body armour |
| body | the `chest` joint | 0, 0, 0.78 | skinned: `rig.ts` gives every vertex the torso's weights (hips / spine / chest by height) and the torso's `build` shape key, then merges the piece into the character mesh. A rigid vest would tear at the belly whenever the chest twists against the hips. |
| ears | on bone `head` | 0, 0.035, 1.425 (between the ears) | rigid; headsets ship two meshes: `<id>` (band over the bare head) and `<id>_nb` (band round the back of the head), and the runtime picks `_nb` whenever a hat is worn |

Body pieces must stay outside the suit with its lapels, buttons and tie (lift >= 0.03 on the chest) and must use zones
the body does not use (not `fur face suit pants tie feet shirt dark white pupil gold mouth tongue suit2 stripeA stripeB
sole fur2 ear square`), because they share the character's palette: the runtime recolours and dulls (broken armour) every
other zone as armour.

## Clips
Monkey (30 fps samples): loops `idle walk run runBack strafeL strafeR cheer`, poses `aim carry`, timed `fire reload melee roll dash hurt throw use defeat`.
`dash` (G1.5 row 14) is the ninja dash that replaces the roll: 20 frames played over 0.34 s, a low forward lunge with the arms swept back. It starts and ends on the same ready stance and eases out of and into it (drop in 0-0.2, hold 0.2-0.74, recover 0.74-1).
Gorilla: loops `idle walk charge stunned sleep`, timed `windup slam hurt defeat`. Timed clips play at `actionT x clip length`.
Gaits are stride-matched: one cycle covers `GAIT_LEN` metres (walk 0.8, run 2.2, runBack 1.64, strafe 1.18).

`kp_common.py` holds what the gun and the attachments share: the modelling kit, the 16-cell palette (15 used, append
only) and the `MAT_Kingpin` material. Frame: x right (ejection port side), y up, z forward along the bore.

**Sockets** in `kingpin45.glb`, all children of `body`, unrotated (a socket's axes are the gun's). `rides` is a custom

point is correct under either parent.

| `socket_rail` | 0, 0.089, 0.494 | `body` | underside of the accessory rail, middle lug |

**Attachments** in `attachments.glb`: one root node each, at the identity, origin at the mount point. Add the node to

| Node | Socket | Tris | Notes |
|---|---|---|---|
| `att_sight_holo` | `socket_sight` | 488 | second primitive `sight_dot` (emissive) |
| `att_sight_2x` | `socket_sight` | 860 | |

`render_fauna.py` needs `tools/blender/build/monkey.blend` (run `build_monkey.py` first): the monkey is the scale reference.

`fauna_lib.py` holds the shared parts: the mesh helpers (on top of `bv_common.py`), the fauna colour zones, the pose
solver and the clip baker. One file per animal (`crab.py`, `parrot.py`, `frog.py`, `boar.py`, `croc.py`) holds its
mesh, bones and clips.

**In the GLB.** One root per animal, at the identity: the armature `fauna_<id>` with one skinned mesh `<id>_mesh` under
it. Bones are named `<id>_<bone>`, so every name in the file is unique and three.js binds a clip to a clone of the root
by name. Clips are named `<id>_<clip>`, baked at 30 fps with a rotation and a location key on every bone on every
frame (a clip never leaves a bone where the last clip put it). Colour is baked: glTF `COLOR_0` (linear) = zone colour
times the AO tint, the numbers `charmat.ts` computes for a monkey; one shared material `MAT_Fauna` (roughness 0.62).
Each root carries extras: `fauna` (the id), `tris`, `clips` (`{clip: {frames, seconds, loop}}`) and the notes below.
Space is the characters': x left, y up, +z forward; the origin is on the ground (the water line for the crocodile).

| Root | Tris | Bones | Clips (seconds, L = loop) | Notes |
|---|---|---|---|---|
| `fauna_crab` | 782 | 14 | `idle` 2.0 L, `scuttle` 0.4 L, `flee` 0.33 L, `burrow` 1.2 | It walks sideways: `scuttle` and `flee` read as moving toward the crab's own left (+x), so yaw it a quarter turn off its heading. `burrow` starts on idle's first frame; only the eyes show from 0.6 to 0.8 of the clip and nothing is above y = 0 at the end. |
| `fauna_parrot` | 1,094 | 9 | `perch_idle` 2.4 L, `takeoff` 0.6, `fly` 0.4 L, `land` 0.67 | The origin is the perch point under the feet in every clip (the body sits about 0.35 above it): the game moves the root. `takeoff` runs from perch_idle's first frame to fly's first frame; `land` runs back. |
| `fauna_frog` | 558 | 11 | `idle` 2.0 L, `hop` 0.8 | `hop` starts and ends on idle's first frame. The arc (apex 0.42 m) is baked on the body bone; the frog is airborne from 0.24 to 0.78 of the clip, so slide the root along the ground only then. |
| `fauna_boar` | 1,312 | 15 | `idle` 2.0 L, `walk` 0.8 L, `run` 0.4 L, `charge_windup` 1.0 L, `charge` 0.33 L, `hit` 0.4, `death` 1.2 | Hooves are planted by IK: one loop covers 0.7 m (`walk`), 1.3 m (`run`), 1.8 m (`charge`) with no slip, so speed = stride / clip seconds. `charge_windup` is a loop (two paws of the right fore hoof per cycle): hold it for the telegraph. `hit` starts and ends on idle's first frame; `death` starts there and ends lying on its right side. |
| `fauna_croc` | 1,720 | 13 | `lurk` 3.0 L, `surface` 0.8, `bite` 0.6, `swim` 1.0 L, `retreat` 1.0, `death` 1.5 | The origin is on the water line. The bind pose is surfaced (back and head out); `lurk` hangs 0.15 m lower (eyes, nostrils and scutes out), `swim` 0.10 m lower. `surface` runs from lurk's first frame to the surfaced pose; `bite`, `retreat` and `death` start on it. `bite` returns to it, and its jaws snap shut 0.95 m ahead of the origin at 0.47 of the clip. `retreat` backs off 0.7 m and ends with nothing above y = 0. `death` ends belly-up. |

**Gates.** `gate.sh` runs the asset QA gate on each animal, `clip_check.py` on every clip (`--arm fauna_<id>` picks the
armature; loops must close, `frog_hop`, `boar_hit` and `croc_bite` must ease out of and into their shared pose, the
boar's hooves must stay on the ground) and `chain_check.py`, which holds the contracts in the table: a one-shot starts
or ends on the exact pose its neighbour starts on, and the mesh sits where the game expects against the ground or the
water at the frames that matter.

## The Vault kit (`tools/blender/build/g_vault.py`, `vault_fac.py`, `vault_fac2.py`)

The home base: the Banana Express pod, the departures board, the room shell and one model per facility. It is a group
of the structures kit, so it builds, exports and loads the same way (`lib.py`, vertex colours with baked AO, no UVs).

```
B=/home/moo/.local/bin/blender
$B -b --factory-startup --python-exit-code 1 --python tools/blender/build/build.py -- --group vault    # -> public/models/build/vault.glb + blend/vault.blend
$B -b tools/blender/build/blend/vault.blend --python tools/blender/build/qa.py                          # QA gate, every piece
python3 tools/blender/build/merge_manifest.py && $B -b --factory-startup --python tools/blender/build/verify_glb.py
node tools/blender/build/check_vault.mjs                                                               # pieces, named nodes, lamp_emit
$B -b tools/blender/build/blend/vault.blend --python-exit-code 1 -P tools/blender/build/vault_review.py -- /tmp/vault_shots all 560
python3 tools/blender/build/vault_sheet.py /tmp/vault_shots research/look/vault_v3                      # the review sheets
BASE=http://127.0.0.1:5354 node tools/vaultshots.mjs research/look/vault_v3/game                        # captures from a production build
```
`BUILD_TRIS=1` on the build prints the triangles each source line adds, per piece. `MONKEY_BLEND=<path>` tells the
review mock where `monkey.blend` is (default: next to the script).

**Space.** Front faces -y in Blender, +z in the game. Facilities, the pod and the board have their origin on the floor
at the centre of their footprint (`home/facilities.ts`, 1 m cells) and stay inside it and under 2.45 m. Shell pieces
that run along a wall have their origin on the floor on the edge of the build grid, and all of their geometry is on
the wall's side of that line, so nothing below the sconces reaches into a build cell.

**Nodes.** Parts keep their bare names in the GLB (`asset.bare`): `pod_door` (pivot on the hinge, rotation.y 0 shut,
-1.9 open), `pod_needle` (pivot on the dial's axle, rotation.z), `pod_lamp` (material `lamp_emit`), `pod_glass`,
`board_face`, `door_wheel`, `sconce_bulb`, `press_wheel` (axis x), `gen_wheel` (axis z), `gen_lamp`, `fx_mag`,
`fx_pack`, `fx_heart`, `neon`, `bell`, `mirror_glass`, `bp_sheet`. Trophy points are `slot0..8`. Rename one and
`home/basebuild.ts`, `home/dispatch.ts` or `home/bunker.ts` stops finding it; `check_vault.mjs` lists them all.

**Materials.** `matte`, `gloss` (polished brass and lacquer), `glass`, `emissive`. The game's versions are in
`src/game/home/vaultkit.ts`. They leave out the canopy cookie the island's kit materials carry, because the vault is
indoors.

**What `lib.py` gained for this kit.** Digits 2, 3, 6, 7, 8, 9 in the stroke font. `Geo.ghost = True` for a fixture
that is hidden until bought: it is lit against everything, but the piece it sits on carries no shadow of it.
`Geo.matname` to name a part's material. Glass never occludes.

**Budget rule.** Under 2,500 triangles a facility, 4,000 for the pod. In this group a box thinner than 7.5 cm or a
rod thinner than 6 cm gets no bevel (`g_vault.py` wraps `Geo.box` and `Geo.cyl`): the bevel is under a pixel at the
bunker camera and costs 32 triangles a box.

**QA habits that bit here.** Two unbevelled boxes that share a face plane z-fight in the gate even when the faces are
hidden, so let trims stop a few millimetres short or stand on the surface instead of sinking into it. Strokes of one
painted letter must not share a plane: leave `paint_text`'s lift on automatic. A loose prop on the floor counts as a
floating part unless it stands on something that belongs to the piece (a rug, a drip tray).
